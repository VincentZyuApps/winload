# 重新整理 max 参数计划

目标：把 Y 轴缩放参数从 `--max` / `--smart-max` 的互斥模型，改成明确的三模式模型。

## 新 CLI

```bash
winload
winload --max-mode smart --max-half-life 10
winload --max-mode legacy
winload --max-mode fixed --max-y-value 10M
```

## 模式定义

| 模式 | 行为 |
| --- | --- |
| `smart` | 默认。使用 smooth peak 指数衰减，尖峰后 Y 轴平滑回落 |
| `legacy` | nload 风格。按当前图形窗口内的最大值自动缩放 |
| `fixed` | 固定 Y 轴上限，使用 `--max-y-value <VALUE>` |

## 参数变化

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--max-mode <smart\|legacy\|fixed>` | `smart` | Y 轴缩放模式 |
| `--max-half-life <SECS>` | `10` | smart 模式指数衰减半衰期 |
| `--max-y-value <VALUE>` | 无 | fixed 模式固定 Y 轴上限，如 `10M`、`1G`、`500K` |

删除旧参数，不做兼容：

- 删除 `-m`, `--max`
- 删除 `--smart-max`

## 参数校验

- `--max-mode fixed` 必须指定 `--max-y-value`
- `--max-y-value` 只能用于 `--max-mode fixed`
- `--max-half-life` 只能用于 `--max-mode smart`
- 单独 `--max-half-life 5` 合法，因为默认 `--max-mode smart`

## Rust 修改点

- `rust/src/main.rs`
  - 新增 `MaxMode` enum：`Smart`, `Legacy`, `Fixed`
  - 新增参数 `--max-mode`、`--max-half-life`、`--max-y-value`
  - 删除 `max` 和 `smart_max`
  - 在解析后做参数校验
- `rust/src/stats.rs`
  - `StatisticsEngine::new` 继续接收 `Option<f64>` 半衰期
  - smart 传 `Some(max_half_life)`，legacy/fixed 传 `None`
- `rust/src/ui.rs`
  - 用 `match max_mode` 选择缩放上限
  - fixed：`max_y_value`
  - smart：`smooth_peak -> next_power_of_2_scaled`
  - legacy：`history peak -> next_power_of_2_scaled`
- `rust/src/i18n.rs`
  - 替换 `help_max`、`help_smart_max`
  - 新增 `help_max_mode`、`help_max_half_life`、`help_max_y_value`
  - 新增 `tag_legacy`、`yaxis_legacy`

## Python 修改点

- `py/main.py`

- `py/ui.py`

## 备注

nload 默认行为对应 `legacy`：按当前图形窗口的峰值缩放。峰值滚出窗口后会下降，但下降是跳变的。`smart` 模式用半衰期指数衰减解决这个突兀回落问题。
