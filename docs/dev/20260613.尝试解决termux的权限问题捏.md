## 一些诊断指令捏

```bash
# 1️⃣ 🖥️ 查看系统信息
fastfetch
# 2️⃣ 📦 安装 winload
curl -fsSL https://gitee.com/vincent-zyu/winload/raw/main/docs/scripts/install/install_gitee.sh | bash
# 3️⃣ ✅ 确认安装位置
which winload
# 4️⃣ ℹ️ 查看版本
winload --version
# 5️⃣ 📖 查看帮助
winload --help
# 6️⃣ ▶️ 首次运行 winload（空白界面）
winload
# 7️⃣ 🔁 再次运行确认问题
winload
# 8️⃣ 🐛 调试：检测网卡数量
winload --debug-info
# 9️⃣ 🚫 诊断：检查 /proc/net/dev 是否可读
cat /proc/net/dev
# 🔟 📂 诊断：检查 /proc/net/ 目录权限
ls -la /proc/net/
# 1️⃣1️⃣ 🐧 诊断：查看内核版本
cat /proc/version
# 1️⃣2️⃣ 👤 诊断：查看用户身份和 SELinux 上下文
id
# 1️⃣3️⃣ 🆔 诊断：当前用户名
whoami
# 1️⃣4️⃣ 🔗 诊断：检查 /proc/net 符号链接目标
ls -la /proc/ | grep net
# 1️⃣5️⃣ 🌐 确认网络接口信息（wlan0 正常）
fastfetch
# 1️⃣6️⃣ 📊 诊断：通过 sysfs 检查网卡统计是否可读
cat /sys/class/net/wlan0/statistics/rx_bytes
# 1️⃣7️⃣ 📋 诊断：查看系统中有哪些网络接口
ls /sys/class/net/

python3 -c "import socket,struct; s=socket.socket(16,3,0); s.sendto(struct.pack('IHHII',32,18,0x301,1,0)+b'\x00'*16,(0,0)); d=s.recv(65536); print('netlink OK, got',len(d),'bytes'); s.close()"
```
